WEATHER STATION V3.1 "AURA"
=============================

This is the internet-researched visual rebuild.

WHY THIS VERSION IS DIFFERENT
-----------------------------
It uses capabilities that polished ESP32/LVGL projects actually use:
- full-screen gradients
- custom vector weather artwork built from LVGL primitives
- real lv_chart temperature graphs
- lv_arc instrument gauges
- layered translucent-looking surfaces
- page-specific layouts rather than one generic card template

The Waveshare ESP32-S3-LCD-2 has a 240x320 IPS ST7789T3 panel,
ESP32-S3R8, 8 MB PSRAM and 16 MB flash, so the hardware is capable
of significantly richer UI than the earlier iterations.

PAGES
-----
Home       atmospheric current-weather hero
Hourly     real LVGL temperature chart
Week       daily high/low range visualization
Details    humidity/UV arcs + wind/pressure instruments
Air        AQI radial gauge + pollutants
Sun        sunrise/sunset scene + moon
Alerts     severity-focused alert center
System     battery/network/memory diagnostics

NOTES
-----
- Weather HTTP uses the full-payload parsing fix that solved IncompleteInput.
- AQI uses Open-Meteo current values.
- Pressure trend compares current pressure to six actual past hours.
- UI renders before WiFi connects.
- Current conditions are cached.
- SD history remains optional.
