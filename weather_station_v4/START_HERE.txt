WEATHER STATION V4
==================

This is the modular build.

FILES
-----
WeatherStationV4.ino   app lifecycle only
Config.h               user + board configuration
Models.h               plain data models
AppState.*             weather intelligence + alerts
Hardware.*             LCD, LVGL port, button, battery
DataService.*          WiFi, NTP, Open-Meteo weather + AQI
StorageService.*       NVS cache + SD CSV history
UiTheme.h              visual design tokens
UiComponents.*         reusable LVGL components
Screens.*              screen compositions

LIBRARIES
---------
ArduinoJson 7.x
Arduino_GFX_Library
LVGL 9.x

FONTS
-----
Only stock:

lv_font_montserrat_32
